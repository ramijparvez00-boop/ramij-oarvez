# Nadra Birthday Website ❤️

This folder is ready for GitHub Pages.

## Files
- `index.html` — main birthday page
- `style.css` — design and animations
- `script.js` — interactions and photo gallery
- `assets/photo1.jpg` ... `assets/photo7.jpg` — your uploaded photos

## GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files and the `assets` folder** while keeping the same structure.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will show the live website link after deployment.

The gallery is already configured. Tap a photo to open it full-screen.
